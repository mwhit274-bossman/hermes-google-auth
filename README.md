# Hermes Google Workspace Connector

Static home page and privacy policy for a private, single-user Google Workspace
OAuth integration used by the Hermes Agent.

Google Cloud requires a publicly reachable home page and privacy policy URL
before an External OAuth app can move from Testing to In production
publishing status. These two pages satisfy that requirement.

- `index.html` — app home page, describes what the integration does
- `privacy.html` — privacy policy, including Google API Limited Use compliance

Published via GitHub Pages.
